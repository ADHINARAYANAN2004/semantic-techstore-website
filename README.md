# 🛒 Semantic TechStore Website

A responsive **E-Commerce website** built using **HTML5 Semantic Tags** and **CSS3**. This project demonstrates modern webpage structure, responsive layout, and best practices for accessibility and SEO.

---

# 📖 Project Description

The **Semantic TechStore Website** is a front-end project designed to showcase an online electronics store. It uses **HTML5 Semantic Tags** to create a well-structured webpage and **CSS3** to provide a modern, responsive, and visually appealing design.

The website includes:

- 🏠 Header with Logo
- 🧭 Navigation Menu
- 🖼 Hero Banner
- 🛍 Featured Product Cards
- 🎁 Offers Sidebar
- 📞 Footer with Contact Information

---

# 🛠 Technologies Used

## HTML5

**Definition**

HTML5 (HyperText Markup Language version 5) is the standard markup language used to create and structure web pages.

### Purpose

- Creates the webpage structure
- Displays text, images, links, and buttons
- Uses semantic tags for better organization
- Improves SEO and accessibility

---

## CSS3

**Definition**

CSS3 (Cascading Style Sheets) is a stylesheet language used to design and style HTML webpages.

### Purpose

- Styles the webpage
- Creates responsive layouts
- Adds colors and typography
- Adds hover effects and animations
- Improves the user interface

---

# 📚 HTML5 Semantic Tags Used

| Tag | Definition | Usage |
|-----|------------|-------|
| `<header>` | Defines the page header | Logo and website title |
| `<nav>` | Defines navigation links | Home, Products, Offers, Contact |
| `<main>` | Represents the main content | Hero banner and product section |
| `<section>` | Groups related content | Hero section and featured products |
| `<article>` | Represents independent content | Product cards |
| `<aside>` | Displays secondary information | Offers and discounts |
| `<footer>` | Defines the footer | Contact details and copyright |

---

# 🎨 CSS Properties Used

| Property | Purpose |

| `box-shadow` | Shadow effects |

| `transform` | Hover effects |
